# About the Project
This project is about loan risk analysis from a loan dataset. We created a debt_to_income(dti) ratio feature which is often more predictive than income alone.

## STEPS PERFORMED:
- Loaded the dataset and cleaned
- Visualize correlations using heatmap 
- Detected and clipped outliers at 90th percentile
- created a Debt-to-Income(DTI) Ratio feature


## Stacks used:
- Python (3.12.3)
- Pandas
- Seaborn
- Matplotlib

## How to run?**
